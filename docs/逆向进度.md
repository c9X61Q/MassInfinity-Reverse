## 与本项目早期版本的差异

| 项 | 早期 | 现在 |
|---|---|---|
| 覆盖率 | 11,902（22.5%） | **51,655（97.6%）** |
| 真实 IL | 8,518 | **42,153（4.9 倍）** |
| 方法身份 | 无（只有 MethodDesc 指针） | `MethodDesc → MVID/token/类型/方法/签名` 键表 |
| 身份绑定方式 | 顺序文件通道（脆弱：并发 JIT/tiering 会错位） | `MethodDesc` 键表 join（无顺序依赖） |
| 覆盖率保障 | 靠目标跑过哪些代码 | `RuntimeHelpers.PrepareMethod` 全量逼 JIT |
| 产物 | IL dump（无法回填） | 回填后的程序集 + 可编译 C# 源码 |
