## upstream-mass-sdk

- 来源：<https://github.com/massarolucien/Mass.Sdk>
- 许可证：**MIT**（见同目录 `LICENSE`，Copyright (c) 2026 massarolucien）
- 内容：Mass 服务的**官方客户端 SDK（C#）**——统一 API 请求封装、鉴权登录、
  连通性检测、桌面端/移动端接口、实例管理，以及全部 DTO/枚举/序列化器与示例工程。
- 为什么放在这里：本仓库分析的目标程序（Mass Infinity 客户端）与它讲的是**同一套服务协议**；
  该 SDK 恰好覆盖目标程序里**被 DNGuard 保护掉的那一层**（HTTP/API 客户端），
  因此是本项目"还原出可编译的 Mass"路线上最关键的公开拼图。
